# Ledger

A **tiny** ledger, with _no_ dependencies. See the [docs](https://example.com/docs "Docs") or `ledger --help`.
Also ~~old~~ news, a [ref link][ref], an ![logo](logo.png), <https://example.com>, a \* escape, a &amp; and <kbd>Ctrl</kbd>.

## Install

1. Download the release.
2. Run the installer:

```sh
curl -fsSL https://example.com/install.sh | sh
```

3. Check it works.

> **Note**
> Entries are limited to 1,024 per account.

- [x] balance
- [ ] export
  - nested item with `inline code`

| Command | Meaning |
|---|---|
| `add` | post an entry |
| `sum` | print the balance |
