## Open

- **The terminal tab is off by default** (owner decision, 2026-11-08: "Skip terminal. Its slow. Will work later."). With a terminal tab open, switching to the Board could send the app into an endless loop inside nsh's reactive runtime, entered from the native terminal view's own signal writes (`native/app/src/terminal/view.rs`, its frame and focused signals): 100% CPU and memory growing to gigabytes. **Not fixed**; notes in `.scratch/dbg5/`. Until it is, `terminalEnabled` is false: nothing offers a terminal and a terminal tab mounts no native view (`TerminalOff`, `design/pane.md`). Turning it on in Settings brings back the old behaviour, bug included. Not rendered (the empty state's look at 1280/960/760, dark, large text are unverified); a terminal agent just started from `Start a terminal agent…` opens that state until its log can be read as a chat. The perf scenarios and shots that open a terminal (`.perf/scenarios.test.tsx`, `.shots/scenarios.ts`) still press `Show terminal` and need the setting seeded before they run again.

- **Inspector**: holds a terminal agent's activity (built, above); still open: Overview, Changes, Files and Terminal as tabs, the subagent line in the conversation opening the subagent there (`showSubagent`), and keeper (ACP) sessions, which have no subagent data; the context meter's home. Files is built as a dock tab (`FilesTab`, `design/files.md`); open there: the viewer filling the tab, a row context menu, the sort remembered between runs, the Escape and column-title presses unverified headless.
- **Dialog cleanup**: about ten dialogs that should be pages, popovers or toasts (see `design/dialogs.md`).
- **Engine**: stable last-activity order (`order_rows` in Rust) and a field for the `quiet 41m` word.
- **Chat**: a scroll-to-end button; the opened diff and output still draw the native code view's grey card (needs a native option); the full diff belongs in the inspector.
- **Renders never taken**: hover states, dark mode for most screens, 960 and 760 px, `fontScale()` 2.0, Linux/GTK, `make a11y`, performance budgets (Linux only).
- **Leftover 36 pt controls** beside 32 pt fields: `components/kit/collapsible.tsx`, `components/board.tsx`, `components/changes-notes.tsx`.
- **Worktrees**: `Remove worktree…` (`worktree.remove`, never the main checkout, never while an agent works in it) and an explicit `Trust this repository` are not built; a created worktree also opens as a shell workspace in herdr.
- **Test hardening**: the session tests that use a real keeper subprocess; any test that fails only in the full run is a flake to fix with `herdr-test`.
- **Earlier messages**: Rust (`load_earlier`, `observed.earlier`) is done and tested; mounting `EarlierRow` and `createAutoLoad` in the transcript is open (`design/chat.md`). Not run against real logs or a remote machine.
- Pictures of a message in a log chat (`components/turn-pictures.tsx`): 72 pt thumbnails in place of `[Image #n]`, fetched on draw, lightbox on press, 16 MiB cap. Tested through the `pictures` scene of `session-lab.tsx` and rendered on macOS (light, dark, 1280); **960 and 760, large text, a real large picture and a real log unverified**.
- Picture lightbox (`components/lightbox-view.tsx`, `lib/lightbox.ts`): replaces the Files viewer's picture step; 3 controls at rest. Rules and end-to-end flows tested; **not rendered (a dialog layer is not in the macOS `app.screenshot`), pointer feel, wheel zoom (scroll-view sensor) and idle fade unverified**.
