# Maintainability

The test is the six-month one: will the next change break because of this, or will the next reader be misled? Everything here is P3 unless it hides a bug, and then it is reported as the bug. Each item has a `check:`, the grep or read that finds it.

- **Two patterns for one job** (principles 6 and 10: one answer dock, toast, palette, guard; migrate every caller). check: grep for a sibling of any helper the change adds (a truncate, a format, a shell-quote, an escape-strip, a popup, a menu, a toast). A new one is a finding when an existing one does the job. A copy that missed a fix is a bug.
- **Clean cutover** (principle 10: no shims, aliases or deprecated paths). check: callers of anything removed or renamed; names with `deprecated`, `legacy`, `compat`, `old`, `v1`; a re-export or alias; comments naming something that no longer exists; `design/*.md` still describing a cut-over piece (`design/attention.md`, `design/board.md` carry such notes).
- **Layering.** `lib/` imports no screens; it may import `components/kit` for feedback (`notify`, `confirmDestructive`, `undoLast`); the kit imports only `lib/motion`, `lib/perf`, `lib/shortcuts`, `lib/settings`, `lib/text`. `herdr-core` is pure Rust with no nsh. Domain persistence is Rust; TSX holds UI-only state. check: imports in changed files.
- **Imports and names.** Project imports are `#lib/`, `#components/`, `#kit`, never `../` or `./` (exceptions: siblings in `components/kit/`, assets, `.ts` test seams). Files are kebab-case; test entries end in `-lab`, `-probe`, `.fixture`. check: `node scripts/absolute-imports.mjs --check`.
- **Kit bypassed.** A screen pasting a kit component's class string, a `Btn` or `Pill` variant that is not in the closed list, hex or alpha on text. check: the greps in `ux-from-code.md`.
- **Motion outside `lib/motion.ts`.** A duration, easing or `transition*` anywhere else; a loop not inside an `If` with `cleanup`; no `reducedMotion()` path. check: grep `transition|duration-|Animated|createMotion|setTimeout`; hand off to `herdr-motion`.
- **Values without a reason.** Raw colour, a bare millisecond or size, an error-message string used as a condition. Sizes from `lib/layout.ts`, motion from `lib/motion.ts`, shortcuts from `lib/shortcuts.ts`.
- **Comments and docs that lie.** Comments say why, never what. check: comments in changed functions that describe the old behaviour; a doc that names the changed behaviour (`docs/`, `design/`: they change in the same change; `DESIGN.md` only for a system rule and under 100 lines; `design/*.md` under 150). `CHANGELOG.md` has a bullet under `## [Unreleased]` for a feat or fix, written for the person using the app.
- **Conditional side effects.** A branch that skips a side effect its sibling performs; a toast or log that says something happened on a path that skipped it.
- **Swallowed errors.** check: `catch {`, `.catch(() =>`, `void promise`, an empty handler, `unwrap` on I/O in Rust, with no comment saying why the failure is fine. A wire error says whether it is fatal or retryable.
- **Dead code.** Unused exports and parameters, commented-out blocks, a tiny one-expression wrapper used fewer than three times, `ReturnType<typeof fn>`, a non-top-level `import type`.
- **Rust.** `cargo clippy -- -D warnings`, no `unwrap` on I/O, no allocation per row on a hot path that a reused buffer avoids, a comment for each `cfg(target_os)` branch, a test for an injection on anything that reaches a remote shell. check: `make core` (formats, clippy and tests of both crates; safe, no pane data).
- **Versions.** 0.1.x patch bumps only; `nsh.json` `version` and `native/*/Cargo.toml` move together. nsh stays 0.4.0 unless asked.
- **Tests that do not catch anything** (`AGENTS.md`, "Tests"). check: tests that pin copy or wording, wiring, source text, incidental defaults (delete or rewrite them); a wall-clock wait (`app.wait(ms)` standing in for a condition: poll the fact or run the clock); `toBeNull()` against `undefined`; an order read from `app.texts().indexOf`; a wait for a status text the screen no longer has (a swallowed 5 s timeout); a test that cannot fail. Also the reverse: a bug fix with no test that failed before it.
